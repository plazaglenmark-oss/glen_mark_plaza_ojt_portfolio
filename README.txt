FILES
- index.html: website content and sections
- style.css: white-and-blue responsive design
- script.js: mobile menu, current year, and back-to-top button
- assets/: put your own optional files here

OPEN THE WEBSITE
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html to preview the website in your browser.
4. For editing, open the folder in Visual Studio Code and edit index.html, style.css, or script.js.

ADD YOUR RESUME
1. Put your resume PDF inside the assets folder.
2. Name it exactly: resume.pdf
3. The Resume button links to assets/resume.pdf.

PROFILE PHOTO

FREE HOSTING WITH GITHUB PAGES
1. Sign in to GitHub and create a new repository, for example: glen-mark-ojt-portfolio.
2. Upload index.html, style.css, script.js, and the assets folder (including resume.pdf if you have one).
3. Open the repository's Settings → Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select the main branch and /(root), then save.
6. Wait for GitHub Pages to publish and use the URL shown on the Pages settings screen.
